# Тайны Нотта — охота на прыгающие поганки

Готовая браузерная 3D-игра с общим онлайн-миром, мобильным джойстиком, редактором студента, четырьмя видами перемещающихся поганок, коллекцией и таблицей лидеров.

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
npm start
```

Откройте http://localhost:3000 . Для 3D-графики требуется интернет: Three.js загружается с CDN.

## Размещение на Render

1. Создайте репозиторий GitHub и загрузите **содержимое папки** (не ZIP): `package.json`, `server.js`, `public/index.html`, `public/game.js`.
2. Render → New → Web Service → подключите репозиторий.
3. Build Command: `npm install`.
4. Start Command: `npm start`.
5. После деплоя откройте URL сервиса. Все посетители одного сервиса видят друг друга.

**Важно о сохранениях:** по умолчанию данные пишутся в `players.json` на файловую систему сервера. На Render без persistent disk данные могут исчезнуть при перезапуске/деплое. Для долгосрочной игры нужен платный persistent disk с переменной `DATA_DIR=/var/data` (если диск смонтирован туда) либо внешняя база данных. Бесплатный сервис может засыпать, из-за чего все подключённые игроки временно отключатся. Для надёжного постоянного мира рекомендуются платный постоянно работающий сервис и постоянное хранилище.

**Безопасность:** имена и секретные коды — простой механизм для небольшого закрытого сообщества, не полноценная учётная система. Не используйте пароль от других сайтов. Секретные коды хранятся в виде scrypt-хешей. Движение и ловля проверяются сервером; защита от злоупотреблений базовая.

## Управление

- Компьютер: WASD, мышь (зажать и вести для поворота камеры), Shift — бег, E — поймать, пробел — прыжок.
- Телефон: горизонтальная ориентация рекомендуется; слева джойстик, поворот камеры пальцем по сцене, справа кнопки прыжка и ловли.

## Особенности

- Общая теплица 32×32, декоративные стены, растения, готическая крыша.
- 26 поганок одновременно, случайные точки появления, обновление примерно раз в 2,5 секунды после поимки; каждые несколько секунд поганки могут смещаться.
- Виды: лесная (1 очко), лунная (3), теневая (5), золотая (10).
- Сохранение внешности, очков, коллекции на сервере.
- Оптимизированные геометрические модели для мобильных устройств, без тяжёлых внешних 3D-ассетов.

## Ограничения версии 1

Это **играбельный прототип**, а не AAA-игра уровня Assassin's Creed: простые стилизованные модели, одна теплица, без квестов, голосового чата и сложных анимаций. Позиции персонажей не сохраняются между сессиями. Одновременно подключённые клиенты при переподключении должны обновить страницу. Не гарантируется стабильная производительность на всех телефонах.
